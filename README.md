# Speak Up Botswana Website

## Project Overview

Speak Up Botswana is a responsive multi-page website focused on **Gender-Based Violence (GBV) awareness, education and support**.

The website provides a digital platform where visitors can learn about GBV, access support and emergency resources, read survivor stories, explore educational content, participate in community events, share their experiences, volunteer and connect with organisations or individuals working to address GBV.

**[View the Live Website](https://dikitsomotona-portfolio.github.io/speak-up-botswana-website/)**

## Pages

* **Home** — Introduction to Speak Up Botswana and access to key GBV information and support resources
* **Stories** — Survivor stories and GBV awareness content
* **Resources** — Educational materials and support resources
* **Connect** — Opportunities to share stories, volunteer and connect with the initiative
* **Events** — Community and GBV awareness activities
* **Register** — Registration functionality
* **Search** — Website search functionality
* **Feedback** — Visitor feedback form
